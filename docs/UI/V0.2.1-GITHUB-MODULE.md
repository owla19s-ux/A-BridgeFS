## 5. Repository 选择器

打开后从 GitHub API 加载：

- Repository name
- owner
- private/public
- permissions
- default branch

选择 Repository 后回写工作区。

## 6. Branch 选择器

只列出当前 Repository 的真实 Branch。

当前 Branch 不存在时显示异常状态，不自动回退为 main。

## 7. 权限显示

UI 中的“读取 / 修改”是 A-BridgeFS 本地工作区权限。

GitHub 实际权限作为底层约束。

因此：

- 读取 ✓：允许 A-BridgeFS 发起读取请求
- 修改 ✓：允许 A-BridgeFS 发起写请求
- GitHub 本身没有权限：操作仍然失败

## 8. GitHub 工作区入口

第一版入口：

- 文件
- Commit
- Issue
- PR
- Actions
- Release

其中尚未实现的能力必须显示“开发中/暂未开放”，而不是假数据显示。

## 9. 系统导航栏

页面底部必须为系统导航/手势区域保留 Insets。

App Bottom Navigation 不得覆盖 Android System Navigation Area。

对话页还必须单独处理 IME Insets。

## 10. 视觉原则

保持现有 A-BridgeFS 白底、橙色强调色和圆角卡片方向。

重点不是增加装饰，而是建立：

- 状态层级
- 资源层级
- 操作层级
- 权限层级
