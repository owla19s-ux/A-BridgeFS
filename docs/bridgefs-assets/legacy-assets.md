# 旧 BridgeFS 资产清单

## 已确认资产

### 指令识别与解析

旧 BridgeFS 已验证可以通过既有指令格式识别操作请求，因此这是 BridgeFS+ 第一阶段应优先继承的核心能力。

### 本地文件执行

已验证的能力包括：

- 文件列表
- 文件读取
- 文件写入
- 路径处理
- 执行结果返回

### Android 本地能力

旧项目已经积累：

- Android 权限处理
- 前台 Service
- Overlay 悬浮入口
- 本地文件访问

### 回执

执行完成后能够返回结果。后续可以在不改变执行核心的前提下标准化为 Receipt。

## 迁移判断

| 资产 | 初步判断 | 备注 |
| --- | --- | --- |
| 指令识别/解析 | 保留 | BridgeFS+ 第一版核心 |
| 文件执行 | 保留 | 已验证 |
| 文件读取/写入 | 保留 | 已验证 |
| 执行结果 | 保留并标准化 | 为后续 API/协作准备 |
| Android 权限 | 参考/迁移 | 根据新工程结构重接 |
| Service | 参考/迁移 | 不直接假设旧实现最终保留 |
| Overlay | 参考 | 新 UI/入口重新设计 |
| 旧测试 UI | 待判断 | 不作为产品核心 |

## 注意

本文件是当前已知资产的初步整理，不替代对旧 BridgeFS 源码的逐文件审计。
