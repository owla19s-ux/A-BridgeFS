# 0.2.1-P2：最小 Tool Calling Runtime + echo_test

状态：开发中

## 目标

验证真实 Provider + Model 是否能够完成：

用户请求 → 模型发起 Tool Call → Android Runtime 执行 echo_test → Tool Result 回传 → 模型完成最终回答。

## 当前实现

- BridgeToolRuntime.kt
- echo_test 单工具
- OpenAI-compatible tools / tool_choice
- assistant tool_calls → tool result 多轮闭环
- 最大 Tool Calling 轮数：4
- MainActivity AI 请求已切换到 chatWithTools()

## 暂不做

- GitHub 工具
- 多工具编排
- Task / Execution / Event 持久化
- Remote Runtime
- Queue / WebSocket / Webhook

## 验收

1. Android Verify 构建通过。
2. 真实 Provider + Model 接受 tools 参数。
3. 模型实际产生 echo_test tool_call。
4. Runtime 正确执行 echo_test。
5. tool result 正确回传。
6. 模型最终返回自然语言结果。
7. 全流程无人工复制粘贴。

## 关键验证

建议用户测试消息：

请使用 echo_test，把 A-BridgeFS Tool Calling OK 原样回显，然后告诉我工具返回的结果。
