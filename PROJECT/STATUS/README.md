# Status

当前项目状态与阶段工作记录统一由 `docs/STATUS.md` 维护。

本目录保留用于状态相关的专项历史资料，例如：

- 仓库审计快照；
- Branch / PR 审计；
- 特定日期的状态检查。

## 当前状态判断

状态必须以实际代码、Commit、Verify、APK 和真机结果为依据。

推荐状态：

- 开发中
- 已设计未实现
- 已实现
- 已构建
- 已验证
- 已发布
- 废弃

不要维护多个互相竞争的“当前状态”文档。

`docs/STATUS.md` 是当前状态与阶段工作记录的主入口；本目录中的日期审计文件属于历史快照，不代表当前 GitHub 状态。
