# UI

正式 UI 资料入口。

当前 APS 正式 UI 定档为三页：**项目 / 对话 / 设置**。

- **项目**：核心项目工作页
- **对话**：独立 AI 对话能力
- **设置**：全局连接、权限与系统配置

旧的“工作区”页面模型，以及 Decision AI / Worker AI 固定分类，不再作为新 UI 设计依据。

当前 UI 资料仍有一部分位于 `docs/UI/`。其中历史资料仅作参考；如与 `PROJECT/UI/` 冲突，以本目录当前正式设计为准。

整理原则：

- 页面结构
- 页面之间的关系
- 交互行为
- 用户可见状态
- UI 与业务功能的对应关系
- 已设计但尚未实现的功能不得伪装成已实现

## 三页 UI 总览

```text
APS
├─ 项目
│  └─ 核心项目工作面
├─ 对话
│  └─ 独立 AI 对话
└─ 设置
   └─ 全局资源与系统设置
```

---

## 1. 项目页面

**定位：APS 的核心工作页。**

核心关系：

**项目 → 任务 → 对话 → API**

项目页包含：

- 项目总览 / 项目展开
- 项目信息
- 项目配置
- 待处理任务
- 项目内历史对话
- 协助 API
- 项目输入区

### 项目配置

项目配置必须通过自身入口独立展开 / 收起。

配置内容包括项目名称、项目地址、API 绑定及其他项目级配置。

### 待处理任务

任务是项目中的工作对象，不是新的 AI 模式。

```text
☐ UI 输入框问题
☐ 构建问题
☐ 签名冲突
```

勾选任务后，任务自动以 `@任务` 形式进入当前输入框；允许同时引用多个任务。

UI 不预设 Decision / Worker 或其他固定 AI 工作模式。

### 项目内对话

项目内对话保存当前项目的历史工作记录。

任务与对话是不同对象：

- 任务：当前需要处理的工作事项
- 对话：项目历史工作记录

### ↑ / ↓ 屏幕显示切换

底部 ↑ / ↓ **只控制屏幕显示空间**。

- 不自动展开 / 收起项目配置
- 不改变待处理任务状态
- 不改变对话区状态
- 不改变项目状态

项目配置仍由自身入口控制。

### 底部结构

```text
内容区
  ↓
App 页面切换区
  ↓
Android System Bar
```

页面切换区不得覆盖 Android System Bar；输入区不得覆盖页面切换区。

## 2. 独立「对话」页面

**定位：直接使用 API 进行普通 AI 对话，并允许访问当前 Project 的项目资源。**

```text
对话
├─ 当前 API
├─ 对话内容
├─ 项目访问
│  └─ 当前项目地址
└─ 输入区
```

规则：

- 可以选择 / 切换 API。
- 可以进行普通 AI 对话。
- 在授权范围内允许访问当前 Project 的项目地址。
- 项目地址读取 Project 的真实配置，不在对话页重复维护一份。
- 实际读取 / 操作能力受当前权限控制。
- 不再出现 Decision AI / Worker AI 分类。
- 不把 GitHub、文件、任务等内部对象全部平铺为独立首页卡片。

因此：

**项目页负责围绕项目工作；对话页负责直接与 API 对话。**

## 3. 设置页面

**定位：全局资源与系统设置。**

设置页采用**分类 + 展开 / 收起**，避免所有设置平铺造成设置大杂烩。

```text
设置
├─ 连接 ▾
├─ 权限 ▸
├─ 文件 ▸
├─ 执行 ▸
├─ 外观 ▸
├─ 通知 ▸
├─ 日志 ▸
└─ 系统 ▸
```

当前一级分类：

1. 连接
2. 权限
3. 文件
4. 执行
5. 外观
6. 通知
7. 日志
8. 系统

一级分类本身在设置页内展开 / 收起；具体二级项目进入对应配置。

### 连接

```text
连接 ▴
├─ API Profiles
├─ GitHub
└─ 其他连接模块
```

API 与 GitHub 均属于全局连接资源。

GitHub 进入具体配置后至少包含：

```text
GitHub
├─ GitHub 账号
├─ Repository
├─ Branch
├─ 访问权限
└─ 模块设置
```

### 权限

权限不是单纯的只读状态展示。

**当前权限状态可查看，并可直接修改。**

权限实际决定 Project、对话及其他功能能够执行的访问范围。

### 设置与其他页面的关系

设置页维护全局资源和系统级配置。

Project 使用真实的项目级配置与绑定关系；对话读取当前 Project 的真实项目地址及授权范围。

不同页面不得各自复制一套互相独立的 API、GitHub、项目地址配置。

## 4. 三页边界

```text
                 APS
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
      项目        对话        设置
       │          │           │
    项目工作     AI 对话      全局资源
       │          │           │
   任务/历史    API/项目访问   连接/权限/系统
       │
    协助 API
```

### 正式边界

- **项目**：核心工作面
- **对话**：独立 AI 对话能力
- **设置**：全局配置与资源管理

三页不得重新互相吞并职责。

## 5. 已明确废弃

以下内容不再作为 APS 当前 UI 架构：

- Decision AI 固定 UI 分类
- Worker AI 固定 UI 分类
- 通过 AI 角色区分“决策 / 施工”
- 项目、工作区、AI 角色、对话混成同一层级
- 为任务制造新的 AI 工作模式

**状态：已定档。**

本文件是 APS 三页 UI 的总入口基线；具体页面细节继续由本目录对应设计文档维护。
