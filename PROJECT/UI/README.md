# UI

正式 UI 资料入口。

当前正式 UI 以 Project（项目）为核心页面。旧的“工作区”页面模型不再作为新 UI 设计依据。

当前 UI 资料仍有一部分位于 `docs/UI/`。Project 页面正式设计以本目录为准。

整理原则：

- 页面结构
- 页面之间的关系
- 交互行为
- 用户可见状态
- UI 与业务功能的对应关系

## Project 页面

Project 页面以**项目主要对话**为中心，不再采用旧版“工作区配置集合”作为主界面。

```text
项目
├─ 项目主要对话 ★
├─ ↑ / ↓ 屏幕显示切换
└─ 项目配置
    └─ 独立点击展开 / 收起
```

规则：
- ↑ / ↓ 只改变屏幕显示区域；
- ↑ / ↓ 不控制项目配置展开状态；
- 项目配置通过自身点击独立展开 / 收起；
- 配置收起后，为主要对话区域留下更多空间；
- 不把 GitHub、API、权限、任务、Verify 等内部对象全部平铺到 Project 首页。

## 独立「对话」

「对话」与 Project 独立，主要承担 API 选择、普通 AI 对话以及允许的读取 / 分析能力。

不要只记录截图或视觉样式；必须能说明 UI 实际连接到什么功能。
